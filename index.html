Copilot remembers things. Here is exactly what, where, and for how long.

How to read this site

Small badges appear next to claims.

Numbers in small boxes are citations. Each one points at an official source card at the bottom of the page, so you can check the claim instead of trusting this site. Anything marked Experimental or Preview can change without notice.

Not a rulebook

Instructions and memory both guide the model. Neither one is enforcement. If a rule must hold every time, it belongs in a hook, a test, or code review — not in a Markdown file.
