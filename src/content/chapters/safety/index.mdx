## What is never stored

- **Detected secrets.** Tokens, keys, and credentials cause the memory to be rejected outright.
- **Model-control tokens.** Recognised patterns are refused as a defence against prompt injection.
- **Sensitive personal or confidential information**, by instruction to the model.
- **Short-lived, task-specific instructions** — memory is meant for things that stay true.

<p class="muted">
  Filtering is not a substitute for hygiene. Do not paste credentials into a chat and assume a
  filter will catch them. <Cite id="gh-copilot-memory" />
</p>

## Staleness is handled by citation, not by trust

A stored fact is not treated as permanently true. Repository facts carry citations to the code that supports them, and before using one Copilot checks those citations against the current branch. That is a judgement, not a guarantee — which is why reviewed instructions remain necessary for rules.

## Retention and expiry

| Rule | Value |
| --- | --- |
| Default expiry for cloud memories | 90 days without reinforcement |
| Configurable range for repository facts | 7–180 days, set by organisation or enterprise |
| Does retrieval reset the clock? | No — only an upvote does |
| When several policies apply | The more restrictive value wins |
| Asking Copilot to forget | Downvotes the memory; permanent deletion is done in GitHub settings |

## Prompt injection and untrusted content

Memory is one more channel through which text can reach a model. Content that the agent reads — a file, an issue, a web page — is untrusted input, and the defence is the same at every layer: treat retrieved text as data, review what gets committed, and keep deterministic checks outside the model.

<Callout variant="warn" label="Shared means shared">
  <p>
    Repository facts are visible to collaborators, and the experimental
    <code>.github/copilot-memories.jsonl</code> file can be committed like any other file.
    Neither is a private notebook. Review before you share.
  </p>
</Callout>

## Cost

Memories included in a prompt count toward token usage and can affect the credits an interaction consumes. A large memory footprint is not free, which is another argument for keeping always-on guidance lean. <Cite id="gh-copilot-memory" />
