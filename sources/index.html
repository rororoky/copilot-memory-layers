Sources and method

This site is a reading aid, not a primary source. Every factual statement is traceable to one of these pages, and each one records the date it was read.

Method

  1. Read the official page directly — documentation, not blog posts or summaries.
  2. Quote the exact sentence when a claim depends on wording.
  3. Record the verification date, because product behaviour changes.
  4. Mark anything experimental or in preview as such.
  5. Leave gaps visible instead of filling them with plausible guesses.

What this site does not claim

  • No internal implementation details. How retrieval is scored, how the vote threshold is set, and how contexts are trimmed are not documented publicly, so they are described here only in the terms the docs use.
  • No promise of stability. Features labelled Experimental or Preview can change at any time.
  • No measurement of your setup. The token counts in the context widget are illustrative, not measurements of a real request.
  • No affiliation. This is an independent educational resource; it is not endorsed by GitHub or Microsoft.

Corrections

If a statement here contradicts the official documentation, the documentation wins. Open an issue with the page URL and the sentence that is wrong, and include the verification date so the correction can be checked against the page as it stood.

Re-verify before relying

Documentation moves. If you are making a decision that depends on a detail here, open the linked source and read the current version.
