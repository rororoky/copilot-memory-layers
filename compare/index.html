Chapter 08 · Working with it

Choosing the right layer

Every “where should this knowledge live?” question has an answer, and it is rarely memory. These tables are ordered by how often the case comes up in practice.

Start with the obligation

If the knowledge is… Put it in Because
A rule that must hold every time Instructions, plus a hook or test Instructions guide; hooks and tests enforce.
A command the whole team runs Project instructions Always included, reviewed once, versioned with the code.
Conventions for one language or folder *.instructions.md with applyTo Costs context only when a matching file is in play.
A repeatable multi-step procedure A skill Bundles instructions, scripts, and templates; loaded on demand.
A task you invoke deliberately A prompt file Stays out of the way until you type the slash command.
Guidance for a specialised role only A custom agent Separates instructions, tools, and model choice from the default agent.
A fact Copilot should keep rediscovering Repository memory Accumulates without maintenance, and is recalled when relevant.
How you personally like to work User memory Follows you across repositories without imposing on collaborators.
State that only matters for this task Session memory or the conversation Discarded automatically, so it cannot go stale.
A credential, key, or token Nowhere Memories are filtered for secrets, and shared facts are not private.

Which instruction artefact?

You want… Use Avoid
Rules in scope for every request copilot-instructions.md or AGENTS.md A dozen file-scoped files that all match **
Different rules for tests and app code Two *.instructions.md files with distinct globs One file full of “if this is a test…” branches
A named workflow you trigger yourself Prompt file, or a skill if it needs assets Pasting the same long prompt every day
A workflow that must run identically every time A hook An instruction that says “always…”
A context-isolated research role A custom agent used as a subagent Loading everything into the main conversation

Local or cloud?

Local memory files Cloud Copilot Memory
Choose when… It is yours alone, or the team has not reviewed it yet The whole team should benefit from a verified repo fact
Audience You, on one machine You, or everyone with repository access
Retention Until changed Expires without reinforcement
Prerequisite Local harness session Paid plan, memory enabled, and repository access

Smell tests

Smell 01

“I keep repeating this”

Repetition is the strongest signal that knowledge belongs in an instruction file, not in your next prompt.

Smell 02

“The instructions are 400 lines”

You are probably storing procedure where you need a skill, or detail where you need memory.

Smell 03

“It worked yesterday”

A stale fact or an expired memory. Verify against the code before rewriting guidance.

Smell 04

“The agent forgot”

Recall is selective. If it must not be forgotten, it cannot live only in memory.
