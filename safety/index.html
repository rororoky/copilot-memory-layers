Chapter 09 · Working with it

Safety, trust, and retention

A system that writes its own notes needs rules about what it may write, how it checks them, and when they disappear. All three are documented, and all three are worth knowing before you rely on memory.

What is never stored

  • Detected secrets. Tokens, keys, and credentials cause the memory to be rejected outright.
  • Model-control tokens. Recognised patterns are refused as a defence against prompt injection.
  • Sensitive personal or confidential information, by instruction to the model.
  • Short-lived, task-specific instructions — memory is meant for things that stay true.

Filtering is not a substitute for hygiene. Do not paste credentials into a chat and assume a filter will catch them.

Staleness is handled by citation, not by trust

A stored fact is not treated as permanently true. Repository facts carry citations to the code that supports them, and before using one Copilot checks those citations against the current branch. That is a judgement, not a guarantee — which is why reviewed instructions remain necessary for rules.

Who controls what

Person

Your settings

Opt out of user preferences, review and delete your memories, and switch memory off per client.

Repository admin

Repository facts

Turn repository memory off for one repository, and review or delete stored facts.

Organisation

Policy and scope

Allow or restrict user preferences, choose which repositories may store facts, and export preferences.

Enterprise

Upper bounds

Set the retention ceiling and restrict repository memory access across organisations.

Prompt injection and untrusted content

Memory is one more channel through which text can reach a model. Content that the agent reads — a file, an issue, a web page — is untrusted input, and the defence is the same at every layer: treat retrieved text as data, review what gets committed, and keep deterministic checks outside the model.

Shared means shared

Repository facts are visible to collaborators, and the experimental .github/copilot-memories.jsonl file can be committed like any other file. Neither is a private notebook. Review before you share.

Cost

Memories included in a prompt count toward token usage and can affect the credits an interaction consumes. A large memory footprint is not free, which is another argument for keeping always-on guidance lean.
